# Справочник полей и кодов Битрикс24

Локальное серверное приложение. Показывает поля сущностей, воронки, стадии и справочники.
Подходит для облака и коробки. Настроек нет: установили, открыли, смотрите.

## Состав

```
index.php        — страница приложения (обработчик)
install.php      — завершение установки (BX24.installFinish)
assets/app.js    — логика (без библиотек)
assets/app.css   — стили
```

Нужен только PHP 7.3+ и HTTPS. База данных, Composer и права на запись не нужны.

## Установка

1. Загрузите папку на хостинг, например `https://example.com/b24-fields/`.
2. В Битрикс24 откройте **Разработчикам → Другое → Локальное приложение**
   (в старой коробке: **Приложения → Добавить приложение**).
3. Тип: **Серверное**, «Использует только API» — **выключено** (приложению нужен интерфейс).
4. Путь вашего обработчика: `https://example.com/b24-fields/index.php`
5. Путь для первоначальной установки: `https://example.com/b24-fields/install.php`
6. Название пункта меню, например «Поля и коды».
7. Права (scope): **crm, lists, user, task, department**.
   Если какого-то права нет, этот раздел покажет ошибку. Остальное будет работать.
8. Сохраните. Приложение появится в левом меню.

## Что умеет

**Поля** (код, название, тип, обязательное, множественное, только чтение, доп. сведения):

- лиды, сделки, контакты, компании, предложения, старые счета, дела, товары, разделы товаров, товарные позиции, реквизиты, банковские реквизиты, адреса, валюты;
- все смарт-процессы и новые счета через `crm.item.fields`. Видны оба кода: `UF_CRM_3_…` и `ufCrm3_…`;
- универсальные списки и процессы в ленте через `lists.field.get`;
- пользователи, задачи (с пользовательскими полями), подразделения.

**Справочники:**

- все записи `crm.status.list` одной таблицей или по отдельному `ENTITY_ID` (стадии лидов, сделок, смартов, источники, типы контактов и т.д.);
- типы справочников (`crm.status.entity.types`);
- воронки сделок и смарт-процессов: ID, `ENTITY_ID` стадий, префикс `STAGE_ID` (`C4:`, `DT128_9:`);
- список смарт-процессов: `entityTypeId`, ID типа, префикс пользовательских полей;
- типы, статусы, направления и приоритеты дел, пользовательские типы дел;
- типы сущностей CRM (`ENTITY_TYPE_ID`), валюты, списки.

**Интерфейс:**

- поиск по всем колонкам с подсветкой. `/` ставит курсор в поиск, `Esc` очищает его;
- галочка **«во всех полях»** ищет код или название по полям всех сущностей сразу;
- сортировка по клику на заголовок: по возрастанию, по убыванию, сброс;
- клик по коду или названию копирует значение;
- клик по строке раскрывает подробности: варианты значений списка (ID / значение / XML_ID) и исходный JSON поля из REST;
- переходы по ссылкам: от поля типа `crm_status` к его справочнику, от воронки к её стадиям, от смарт-процесса к его полям;
- «Копировать таблицу» копирует видимые строки с разделителем TAB, они вставляются в Excel или Google Таблицы;
- последняя открытая сущность запоминается.

## Как это работает

Битрикс24 открывает `index.php` в iframe. Все REST-запросы выполняются в браузере через
BX24 JS SDK (`BX24.callMethod`) от имени текущего пользователя. Поэтому:

- на сервере не хранятся ни токены, ни настройки, и обновлять OAuth не нужно;
- один и тот же код работает в облаке и в коробке;
- пользователь видит только то, на что у него есть права. Чтобы видеть все поля, открывайте приложение под администратором.

Данные кэшируются на время открытой вкладки. Кнопка «Обновить» загружает их заново.

## Добавить свою сущность

В `assets/app.js` найдите `CRM_FIELD_METHODS` и добавьте строку:

```js
['mykey', 'Название в списке', 'crm.something.fields'],
```

Если метод отдаёт другой формат, добавьте `addSource({...})` в `buildStaticSources()` по образцу соседних.
